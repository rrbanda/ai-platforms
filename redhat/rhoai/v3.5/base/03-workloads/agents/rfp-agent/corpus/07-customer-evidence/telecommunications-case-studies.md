# Telecommunications Case Studies

## Verizon

| Metric | Value |
|---|---|
| Subscriber base | 143 million (converting to 5G) |
| Edge locations | 1000s (Single-Node OpenShift) |
| Red Hat consultants embedded | 50+ |
| Partnership duration | 15+ years |
| Recognition | Red Hat Innovation Award 2023 |

- Built 5G core network on Red Hat OpenShift.
- **Single-Node OpenShift (SNO)** deployed across thousands of edge locations for low-latency 5G workloads.
- **Red Hat Advanced Cluster Management** provides end-to-end visibility and policy-based governance across all clusters (core, regional, edge).
- 50+ Red Hat consultants work alongside Verizon engineering teams on platform development, CI/CD, and operations.
- Red Hat Innovation Award 2023 recognized the scale and impact of the 5G core transformation.

## VodafoneZiggo

| Detail | Value |
|---|---|
| Market | Netherlands |
| Platform | Red Hat OpenShift |
| Migration | Red Hat OpenStack Platform (4G) → OpenShift (5G) |

- Selected Red Hat OpenShift as the hybrid cloud platform for **5G standalone core** network.
- Migrated from Red Hat OpenStack Platform, which ran the 4G network infrastructure.
- **Red Hat Consulting** engaged for production rollout — architecture review, deployment automation, operational readiness.
- Adopted **DevSecOps** practices: automated security scanning in CI/CD pipelines, policy-as-code for network function deployments.

## Telenor

| Detail | Value |
|---|---|
| Use case | 5G network slicing, edge AI |
| Platform | Red Hat OpenShift, Red Hat Device Edge |
| Multi-vendor partners | Nokia, Oracle, Intel, Druid Software, TCS |

- 5G network slicing and edge AI workloads running on Red Hat OpenShift.
- **Red Hat Device Edge** for low-power, resource-constrained edge deployments (cell towers, micro data centers).
- **Red Hat Advanced Cluster Management** for fleet management across core and edge clusters.
- **Red Hat OpenShift AI** for AI model lifecycle management at the network edge — inference for real-time traffic optimization, anomaly detection.
- Multi-vendor platform architecture with Nokia (RAN), Oracle (BSS), Intel (hardware), Druid Software (private 5G), and TCS (systems integration).

## Vodafone Group

- Uses Red Hat OpenShift as the container platform for cloud-native network functions (CNFs).
- **GitOps** workflows for network function deployment and configuration management.
- **Validated patterns** for repeatable deployment of telco workloads across markets.
