## Cloud Partners

### Amazon Web Services (AWS)

- **ROSA (Red Hat OpenShift Service on AWS):** Jointly managed OpenShift, SLA-backed, integrated billing through AWS Marketplace.
- **EKS integrations:** Red Hat Ansible Automation Platform certified on Amazon EKS for hybrid management.
- **AWS Trainium support:** AWS Trainium accelerators validated for OpenShift AI model training workloads.

### Microsoft Azure

- **ARO (Azure Red Hat OpenShift):** First-party Azure service, jointly engineered and supported by Microsoft and Red Hat.
- Integrated with Azure Active Directory, Azure Monitor, and Azure networking.
- Available in Azure Government regions for regulated workloads.

### Google Cloud

- **OpenShift on GCP:** Red Hat OpenShift Dedicated available on Google Cloud infrastructure.
- **AI Hypercomputer:** Google Cloud AI Hypercomputer validated with OpenShift AI for large-scale training.
- Integration with Google Cloud networking, storage, and identity services.

## Hardware Certification

The **Red Hat Ecosystem Catalog** (catalog.redhat.com) provides a searchable registry of:

- Certified hardware platforms (servers, storage, networking).
- Certified cloud providers and instance types.
- Certified software applications and operators.
- Certified container images.

All certifications are version-specific — a given hardware platform is certified against specific RHEL and OpenShift releases. Certification includes joint support agreements where Red Hat and the hardware vendor coordinate on issue resolution.
