# Red Hat Training & Certification

## Exam Philosophy

All Red Hat certification exams are **performance-based**. Candidates complete real tasks on live systems — no multiple-choice questions. Exams are proctored and time-limited. This format tests actual operational competency, not memorization.

## Core Certification Paths

| Certification | Exam Code | Focus | Prerequisite Courses | Notes |
|---|---|---|---|---|
| Red Hat Certified System Administrator (RHCSA) | EX200 | Foundation Linux admin | RH124, RH134 | Based on RHEL 10 |
| Red Hat Certified Engineer (RHCE) | EX294 | Advanced automation with Ansible | RH294 | Requires RHCSA |
| Red Hat Certified OpenShift Administrator | EX280 | Cluster administration | DO180, DO281 | OpenShift Container Platform |
| Red Hat Certified Specialist in OpenShift Automation and Integration | EX380 | CI/CD, operators, automation | DO380 | Advanced OpenShift |

### RHCSA (EX200)

- Entry-level certification for Linux system administration.
- Covers user management, file permissions, SELinux, storage, networking, container basics.
- Exam based on Red Hat Enterprise Linux 10.
- Preparation path: RH124 (System Administration I) → RH134 (System Administration II).

### RHCE (EX294)

- Validates ability to automate Linux administration tasks using Red Hat Ansible Automation Platform.
- Covers playbook development, roles, collections, inventory management.
- Requires active RHCSA to earn RHCE credential.

### OpenShift Administrator (EX280)

- Validates cluster deployment, configuration, and troubleshooting.
- Covers pod scheduling, networking, storage, authentication, quotas.
- Preparation: DO180 (Introduction to Containers) → DO281 (OpenShift Administration).

### OpenShift Specialist — Automation & Integration (EX380)

- Advanced OpenShift topics: operator development, GitOps workflows, CI/CD pipeline integration.
- Targets platform engineers building automation around OpenShift.

## Knowledge Transfer in Consulting Engagements

Red Hat Consulting engagements include structured knowledge transfer as a standard component:

- **Pair programming** — Red Hat consultants work alongside customer engineers during implementation.
- **Architecture workshops** — Documented design decisions and rationale delivered as artifacts.
- **Documentation handoff** — Runbooks, operational procedures, and architecture decision records produced during the engagement.
- **Enablement sessions** — Targeted training on the specific configurations and patterns deployed.
