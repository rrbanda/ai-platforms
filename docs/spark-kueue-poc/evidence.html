TC-6: Retry Behavior Comparison

PASS

Kueue Eliminates Retry Storms

Same oversized job with restartPolicy: OnFailure, tested with and without Kueue.
With Kueue
STATUS: SUSPENDED | Pods: 0 | retryCount: 0
Kueue holds the job — no retry storm, no pod churn.
Without Kueue
Operator creates pods → FailedScheduling → timeout → restart
→ creates pods again → same failure → restart loop
Pod churn: 5 pods created/destroyed per attempt

PASS

Key Finding

Recovery mechanism: The Spark driver (not the Operator) handles executor replacement via its built-in KubernetesClusterSchedulerBackend. Detection delay: ~30s (spark.kubernetes.executor.missingPodDetectDelta default). Job completed with executionAttempts: 1 — no full restart needed.
