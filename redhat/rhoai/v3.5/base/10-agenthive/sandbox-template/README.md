# Agent template (ops)

Copy this directory to `agents/<name>/`, then follow [platform/docs/04-agent-deployment.md](../docs/04-agent-deployment.md).

Use this template for cluster/ops agents (OpenShift MCP, cron, GitOps PRs).

For a RAG agent with a corpus and EvalHub collection, copy `agents/rfp-agent/` instead.

Replace every `example-agent` string (namespace, Sandbox name, ConfigMaps, Route, SKILLS, policy ConfigMap name).
